## 2026-11-07 固定样本与真实接口

本批在独立源码副本、虚构 SQLite 和本机 H5 构建中操作正式页面，使用实际 FastAPI 路由与服务。候选发言预先写入固定样本，没有启动应用后台生命周期，没有调用模型或 Embedding，也没有读取开发数据库、头像或配置。

源码基线为 `649f11d` 加当时未提交的 M6-C 改动。归档保留工作区补丁、后端源码副本、前端源码散列、H5 构建与散列；本报告只说明该版本的首批交互验证。M6-C 的后端 784 项、前端 296 项及三端构建结果见 [交付记录](../../plans/group-chat/M6_INTERFACE_AND_ACCEPTANCE.md#m6-c-成员立绘与候选恢复)，本批没有重新执行这些全量检查。

隔离服务不启用生成能力，服务端另外拒绝生成、续接与删除请求。页面发送不可用；采用切换、撤回、立绘变更与创建操作写入独立测试库，测试结束后停止服务。

## 实际覆盖

| 场景 | 实际观察与交叉核对 |
| --- | --- |
| 详情与状态 | 入群起点按需展开；当前状态显示候选归属，固定样本无成长时显示暂无资料，不伪造成长结果 |
| 成员独立立绘 | 查询本人角色素材，选择已有立绘后重新 GET，当前采用标识更新；再切换头像，两个成员均回退头像 |
| 其他候选预览 | 候选 2 标明“仅预览，未采用”，同时保留候选 1 的当前故事正文；不因查看而发起选择请求 |
| 采用切换与恢复 | 切到候选 2 后正文更新，两个成员恢复各自立绘；切回候选 1 并刷新立绘后恢复两人的头像，页面重载仍保持候选 1 |
| 撤回确认 | 取消后轮次仍在；确认后进入无发言空态，刷新立绘恢复群内起步选择；数据库保留两份候选快照 |
| 混合来源创建 | 列表进入创建，标题与双成员校验生效；成员 1 选单聊快照、成员 2 选原卡，创建后显示继承好感度 37、心情、认知及 2 张记忆卡，来源单聊保留 |
| 窄屏与宽屏 | 在 320×740、390×844、1024×768 浏览器视口检查，页面宽度分别等于视口宽度；长成员名换行，PNG 立绘按比例显示，正文保留换行 |

HTTP 审计共记录 6 次成功写入：2 次立绘 PUT、2 次采用切换 POST、1 次撤回 POST 和 1 次创建 POST。数据库复核候选 1 保存两个头像选择，候选 2 仍保存两名成员原立绘 ID；预览及页面刷新没有增加写请求。取消与确认之间曾因弹层关闭动画过早操作而未提交，等待当前弹层状态后重新确认成功；不将中间状态记作已撤回。

## 测试环境问题与原始证据

准备过程中保留了健康路由覆盖首页、前后端 `/assets` 冲突，以及只读预览按设计拒绝写入的尝试。最终使用 `/preview/` 下的普通 H5 构建，API 指向独立本机端口；没有放宽正式只读预览模式。

最初使用的 SVG 测试立绘在本机静态服务的 `image/svg` MIME 下触发头像回退。改用上传接口实际支持的 PNG 固定素材后，浏览器解码宽度为 320，候选切换后图片显示正常。原 SVG、回退截图和最终 PNG 证据分别保留；本批没有修改正式图片组件或静态服务。

本地归档批次为 `2026-11-07-m6-d-h5-1caba489`，入口是 Git 忽略目录 `docs/local/group-chat-tests/README.md` 与 `index.json`。包含 DOM 记录、截图、HTTP 日志、数据库状态、请求记录及环境修正说明；前置尝试以独立编号保留。归档不随仓库分发，正式结论与限制以本报告为准。
