## 页面与状态边界

详情首先展示故事身份与当前采用内容，成员来源和入群状态按需展开。发言按成员 Persona 匹配头像，正文保留原有顺序与换行；头像缺失使用通用组件的回退，不用姓名匹配身份。当前页继续沿用最近轮次在前的分页方式，不在本批引入自动滚动或流式聊天。

候选预览保持显式的“仅预览，未采用”标记。预览状态绑定候选，不能覆盖成员入群起点。后续当前状态面板应绑定服务端返回的群版本和采用候选；查询期间发生选择、撤回、确认或换服务器时，旧响应失效。不能通过主动读取隐藏知情记录或内部导演审计拼出产品状态。

发送、重生成、采用、续接与撤回继续由现有 composable 执行，按钮权限继续使用服务端 capabilities 和现有失效检查。未知提交只用原 UUID 查询，不能因界面刷新或拆组件再次提交。删除仍需明确确认，失败与取消沿用原有反馈和锁释放规则。

三端使用 uni-app 组件和条件编译，不把浏览器 DOM 或专用 CSS 交互当作通用能力。复用语义变量、状态反馈与安全区；键盘遮挡、滚动高度和触控目标在真机另行核对。

## M6-C 成员立绘与候选恢复

2026-11-07 接入手动成员立绘，资源继续由角色档案管理。详情按需读取当前全员立绘，可分页选择已有素材或回退头像；采用内容、候选预览和成员状态均读取各自候选的图像，不根据台词或心情自动猜测表情。

新候选的 `portrait_selections_json` 保存 Persona ID 到立绘 ID 的完整映射。首次发送和整轮重生成在原接受事务中冻结当前采用选择；新候选失败时不改变旧采用结果，显式续接沿用原快照。修改选择只允许尚无轮次的群内起步选择，或最新未确认采用候选；更新在会话锁和短写事务内核对群版本、轮次、候选及 revision，保存后递增群与候选版本。切换和撤回不复制其他候选数据。

起步选择使用群内 Persona 的现有 portrait_base，不改写来源快照。迁移 `b7f8a9b0c1d2` 追加可空列，旧候选不回填，缺快照时使用不可变入群选择；已有快照时拒绝有损降级。删除素材只使解析回退头像，不删除历史候选或改写其 ID；资源回收继续沿用既有 Outbox。

前端 `useGroupPortraits` 使用现有页面代际与服务器捕获机制，按采用版本使旧读取失效。立绘写入期间清空旧采用信息并阻止聊天写操作，写后重新 GET 轮次和立绘；提交结果不确定也只查询，不自动重发 PUT。离页、换故事、A→B→A 切服与过期写完成不能恢复旧图片或解锁新请求。Mock 明确拒绝新查询和选择，旧服务器仍可用头像阅读。

本批专项覆盖独立选择、旧来源不变、候选切换、失败与续接、确认/撤回、资源归属、删除回退、提交回滚、锁与旧库升降级；调用方有未提交修改时拒绝执行，不隐式 flush。前端覆盖版本捕获、一次 PUT、未知结果只读恢复、素材分页与迟到结果隔离。

2026-11-07 最终源码的隔离后端全量 784 项、前端 296 项、类型检查与 H5 / App Plus / 微信小程序构建均通过。API 文档专项 3 项通过；正式文档链接检查 52 个 Markdown、0 错误。首次后端全量 783 项有 3 项失败，原因是迁移测试仍固定旧 head 或历史列清单；修正测试断言并追加事务保护回归后，执行上述最终全量。原始失败与复验日志保留在本地证据目录。
