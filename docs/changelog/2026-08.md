## 2026-08-05

### 修复：TTS 长文本未提炼并回退原文

- TTS 文本预处理改为结构化 JSON 契约，明确区分正常台词与
  `no_speech`，不再把空输出误判为应当朗读原文。
- `deepseek-v4-flash` 辅助调用显式关闭 thinking，避免 reasoning 占满
  1024 token 输出预算后留下空正文。
- 800 字符以内按短文本提取处理；更长输入要求保留关键事实、角色口吻并
  压缩到最多 500 字符。
- 检查模型 `finish_reason`、JSON 结构、清洗后正文和长文本输出长度；截断
  或不合格时自动执行一次强化压缩重试。
- 模型输出连续两次不合格，或调用发生网络/供应商故障时，仅保守提取明确
  引号内或目标角色名前缀后的台词；超长且无法确认说话内容时返回空结果，
  禁止整段原文进入语音模型。网络故障不会重复等待第二次超时。
- 统一同步与异步路径的提示词、解析、清洗、质量校验和安全回退逻辑。
- TTS 缓存文件名和普通文本哈希加入预处理器版本 `p2`，自动避开旧版已
  生成的原文音频。

### 验证

- 新增 7 项离线回归测试，覆盖短文本、长文本截断重试、纯旁白、模型故障、
  多说话人过滤、未知控制标签以及空结果阻断。
- 使用当前 `deepseek-v4-flash` 真实抽样：1482 字英文重复长对白压缩为 166
  字并保持原语言；2085 字多人文本仅保留目标角色的 70 字内容。
