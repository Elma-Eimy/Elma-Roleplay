### 改进：记忆写入准入与持续状态更新

- 近期十二张卡与较早向量候选分开检索，距离阈值外仍补充最多两个最近邻供模型比较。候选预算有界，距离不直接决定归并；故事、分叉、时间与来源校验保持一致。
- 增加高权重长反应、持久状态与承诺保护、条件补全和取消、来源指纹、无效关联、超长保留及远邻候选回归；真实模型评估记录保存在仓库外。

## 2026-10-25

### 改进：持久事件身份与阶段事实保留

- 三批、容量、来源条数和正文长度上限改为保存阶段快照，保留事件 ID；只有模型明确结束才关闭身份。阶段卡通过外键关联同一事件，分叉仅继承可见阶段，父故事可继续原身份。新增迁移保留旧库与回退路径。
- 跨批摘要改为追加本批进展，旧片段不被模型整体重写；阶段之间独立保存来源，自动查重不替代旧阶段，手动整理保留同一事件 ID 并拒绝不同明确身份。新增十二批固定虚构对话回放，检查十二项事实线索和重启、容量后的身份延续；字面线索指标不作为真实模型提取质量结论。
- 真实 API 回放发现模型可能自行给新事件编号，现明确禁止新建数字 ID，并对事件卡的越界或非法类型 ID 增加一次带可用 ID 范围的纠正重试；再次失败仍可靠入队，不猜测归属，不打印原文。
- 非事件卡多余的 `event_status/buffer_id` 字段不再触发整批失败，按实际记忆类型处理且不读取其事件引用；事件卡 ID 仍严格校验，不将关系卡擅自转换为事件。

### 改进：记忆候选持久重试与事务隔离

- 候选与接收进度先原子入队，依赖组件独立处理；向量查询和关系模型在事务外执行，提交时复核租约、来源和版本。新增迁移、同故事处理唯一约束和独立重试 Worker，停机等待处理线程，失败无需新聊天即可恢复，聊天保留有效待处理候选。
- 关系判断接收时间与来源元数据，正文重复但时间更明确时创建版本，旧消息补处理不覆盖新事实。事件与图谱辅助来源分别失效；手动接口、前端类型与 Mock 返回真实处理状态，界面不再把待重试显示成成功。

### 修复：事件碎片合并与收尾图谱边界

- 同批事件合并超长时提前收尾并保留后续片段，情绪片段无法完整放入宿主时独立保存；不再截断拼接正文后仍将来源片段标为已吸收。
- 容量收尾项与持久缓冲共用跨卡依赖绑定，依据不完整的图谱不发布；非法图谱下标不再在吸收重映射时触发异常。增加全文保留、实体与关系的完整依据及失效、未落库依赖和非法下标回归。

### 功能：跨批次进行中事件缓冲

- 新增 SQLite 事件缓冲及迁移，模型可持续补充同一事件；稳定事实和明确承诺可直接写入，事件在结束、容量或批次上限、手动提纯时收尾，保留跨批次消息指纹。缓冲同步进入聊天动态背景，重启后可继续处理。
- 支持跨批次时间状态从 unknown 收敛与补充时间说明、同批瞬时伴随情绪碎片吸附及跨卡图谱证据延迟绑定；缓冲、记忆、图谱、Outbox 与提取指针原子提交，分叉仅收尾完整位于边界内的父故事事件，详见进行中事件说明。

### 改进：记忆写入前查重与实际写入统计

- 写入查重独立于聊天召回，联合语义距离候选、SQLite 近期可见卡和本批新卡，支持相容时间状态（如 current 与 unknown）匹配与冗余当前时间附注归一；整理预览新增高相关候选配对线索提示并支持补充碎片继承明确时间语义与来源指纹。
- 关系判断或必要的索引查询失败时整批回滚，保留消息指针供后续触发重试；新增脱敏的提取结果日志，`extracted_count` 改为实际提交行数，复用旧卡不再计为新增。失败重试沿用消息进度，没有独立候选重试队列。

### 修复：按记忆类型隔离整理模型输入

- 同批原卡先按事件、事实、关系、情绪类型分别送检；非事件类型仅允许同类型去重，每次返回只校验本次输入的来源 ID，避免混合类型上下文诱发非法事件归并。
- 各类型共享整批 12 组预算，为后续可归并类型保留名额，统一编号后原子保存；任一类型检查失败均不保存整批预览或扫描进度。日志补充类型、调用预算与整批类型数量，质量验收保留各次调用并覆盖混合类型和整批预算回归。

### 修复：启动迁移保留诊断日志与整理类型纠正

- 应用内 Alembic 迁移不再重置宿主日志配置，命令行迁移保留已有日志器；修复服务重启后整理诊断和 Uvicorn 日志被禁用的问题，增加独立进程中的真实迁移日志回归。
- 事件组含非事件卡、分组混合记忆类型时，最多要求模型纠正一次，仍使用相同来源并执行全部校验；纠正失败不保存预览或推进扫描，不擅自改写卡片类型或合并类别。

### 修复：记忆整理返回格式兼容与失败诊断

- 整理预览兼容模型直接返回分组数组；JSON、对象结构或分组数量错误最多纠正重试一次，仍保留 12 组上限与全部来源安全校验，失败不推进扫描进度。
- 增加 `[MEMORY CONSOLIDATION]` 诊断日志，区分结构、数量、来源、正文长度和输出截断；仅记录规模、原因码及关联信息，不记录记忆正文、模型原文或凭据。细分用户错误提示，补充数组兼容、纠正重试、日志隐私及长原卡回归。

## 2026-10-22

### 完善：CHARX 上传边界、兼容计划与导入恢复

- 在读取请求体前校验访问凭据，按实际流量限制 multipart 请求大小、并发数及文件数量，阻断鉴权前无限暂存。
- ZIP 素材读取前占用预算，损坏图片不返还；重复引用缓存成功或失败结果，避免反复解压。解码移出生命周期锁，取消和其他预览操作可继续。
- 新增显式 CCv3 导入计划、兼容性清单、跳过素材明细和确认摘要，区分创建角色与追加素材；不承诺原平台行为完整还原。
- 立绘默认按内容摘要去重，可显式保留重复记录；同内容文件复用并沿用 Outbox 引用检查，新增兼容旧库的摘要迁移。
- 新增导入状态查询，响应丢失时恢复回执；结果不确定时锁定选择并重试原请求。生命周期任务每 60 秒清理过期预览。
- 验证：完整后端隔离回归 375 项、前端离线回归 136 项通过；迁移、上传边界、共享文件回收、旧预览失效及断网恢复状态均有自动回归。类型检查及 H5/App Plus/微信小程序构建通过；真实设备上传与断网恢复尚未验收。

### 修复：CHARX 坏图容错、解码预算与预览方向

- PNG 校验码损坏时跳过该素材并保留其他可用图片，避免整个预览返回 500。
- 图片在校验和解码前计入累计像素预算，损坏图片与重复引用的失败尝试同样占用预算，防止绕过解码总量限制。
- 缩略图应用 EXIF 旋转与镜像信息，原始导入图片保持不变；新增坏 PNG、重复截断 JPEG 预算与 EXIF 方向回归。
- CHARX 后端隔离回归 16 项通过；本次仅修改后端图片预览与文档，未重跑前端构建或完整后端回归。

- 对压缩路径、文件数、解压总量、单图、总像素及重复引用暂存大小设限，拒绝加密包、符号链接和嵌套压缩包；不访问素材外链、不加载原平台模块或脚本，对缺图、非图片、变量界面等明确提示。

- 关联有效整理的来源卡及整理产物保持只读；撤销恢复当前故事原卡，已有子故事仍引用的来源继续保护。前端关闭、换会话和换服务器后忽略旧请求回调。
- 新增隔离后端、旧库迁移和前端异步/API 回归；离线 Mock 明确提示不支持模型整理。

### 优化：流式对话断连后台持久化与会话状态同步

- 后端重构 `POST /chat/stream`，将大模型流式推理与持久化落库（`_run_stream_worker`）从 HTTP/SSE 传输生命周期中解耦。当客户端中途断开连接（如退出会话、离开页面或网络抖动）时，后台 Worker 依然完整拉取回复、解析状态并写入数据库，同时触发记忆提纯与认知更新，避免未完成回合被意外回滚与消息丢失。
- 引入会话级锁状态检查 `is_session_locked(session_id)`，并在 `GET /sessions/{session_id}/history` 响应中暴露 `is_generating` 字段。
- 完善 Worker 取消与应用生命周期集成：Worker 将回滚清理移入 `finally` 块，确保发生 `asyncio.CancelledError` 时依然安全执行 `abort_chat_turn` 清理用户消息；在 `application/lifecycle.py` 关闭流程中接入 `cancel_all_stream_tasks`，避免服务重载遗留孤儿数据。
- 修复重新生成（Regenerate）时因旧 assistant 存在导致轮询误判完成的问题：严格以 `!is_generating` 为完成判断准绳。
- 修复页面内断网导致假失败与重复回合问题：前端流式网络中断后平滑接入后台轮询探活与自愈恢复，保留占位并拉取后台生成结果，避免把未失败回合错误标红。
- 增强长思考/慢模型生成支持：服务端仍在生成时持续轮询，连续网络错误达到上限后提示状态尚未确认，不重复提交聊天请求。
- 补充后端断连持久化、锁释放、取消清理、lifespan 集成与前端重新生成轮询、断网自愈回归测试。
- 修复断连恢复把旧回复误判成本轮成功的问题，以发送前的消息及候选 ID 边界识别新结果；失败时保留用户原话、恢复旧候选，重新进入会话后同步已清理的历史，并为 App 接入同一恢复流程。
- 关闭或重载时等待在途写库和清理完成后再释放 Session 与会话锁，避免保存、回滚和关闭并发；历史读取期间生成结束时保守返回生成中，确保客户端再次拉取最终历史。
