## 2026-11-04

### 修复：M2-A 事务拒绝与关闭运行权

- 群聊内部服务在重置事务前拒绝调用方的待提交修改或活动 SQLite 事务，预读取禁止 autoflush；拒绝时保留调用方修改，避免误回滚。
- 后台 Worker 异常或关闭被重复取消时，等待全部后台任务及聊天流清理后再释放数据库运行权；补充失败复现与取消回归。

### 工程：群聊 M2-A 轮次与个人历史基础

- 增加轮次、候选、内容和知情表，以组合外键限制同群归属；内部写入原子保存完整知情结果，个人历史按候选与可见性筛选后限量，缺失记录默认隐藏。
- 增加保留旧数据的迁移、级联删除与回滚回归；启动取得数据库文件运行权后处理残留候选，阻止多进程误标和自动重发。群聊生成和历史 HTTP 接口尚未开放。

### 设计：群聊 M2 发言与知情隔离

- 新增 [M2 设计稿](../plans/group-chat/M2_CONTEXT_AND_VISIBILITY.md)，定义独立轮次/候选/内容、候选所属知情记录、个人 Prompt 与单步生成失败边界。
- 拆分 M2-A–D，明确只读展示和内部原型范围、全文知情粒度的待验证限制，以及与 M3–M5 的交接；尚未实现群聊生成。

### 功能：群聊 M1-D 最小创建查看界面

- 故事首页增加群聊入口，接入独立列表、固定成员创建、原卡/单聊快照来源选择、详情和整群删除，明确当前不支持角色互动。
- 增加提交参数冻结、重复提交防护、结果不确定反馈，以及离页、切服和过期确认的响应隔离；补齐返回页面后的来源加载恢复、相同模式保留选择的回归，并完成隔离 H5 流程检查。

### 功能：群聊 M1-C 接口与前端领域接入

- 开放群聊创建、分页、详情和整群删除 HTTP 接口，明确群聊目标与单聊来源策略，保留鉴权和双向类型隔离。
- 补齐前端 API、类型、原卡起步 Mock 和正式契约；来源快照 Mock 明确不支持，创建失败不自动重发，页面入口留待 M1-D。

### 功能：群聊 M1-B 来源快照与聚合服务

- 实现内部群聊创建、列表详情与整群删除，原子冻结来源当前状态及有效记忆，保留分支和整理边界，来源修改或删除不影响快照。
- 增加快照表迁移、Outbox 删除原子性、并发引用保护与隔离回归；群聊 HTTP 接口和前端尚未开放。

### 工程：自动执行单聊访问边界

- 所有 HTTP 路由默认校验会话、消息及人格归属，新增接口无需手动调用检查；装配时拒绝绕过统一边界的路由。
- 自动发现资源服务入口并验证群聊拒绝和无副作用，共享算法显式说明例外；保留后台任务的领取取消与重试保护。

### 工程：收敛单聊资源加载边界

- 会话、消息和人格统一在资源加载时检查所属故事类型，移除调用方分散的查询后校验；历史、状态、立绘和 Prompt 内部复用已加载对象。
- 保留独立服务与后台入口的群聊隔离，补充单次校验、跨故事人格拒绝写入及现有流式状态竞争回归。

### 工程：群聊 M1-A 数据与单聊隔离

- 增加会话类型和多人格位置约束，保留单聊只读人格访问；旧入口拒绝操作群聊，单聊分页排除群聊，阻止删除群聊引用的角色。
- 增加保留旧数据的事务迁移与失败回滚校验、降级保护和入口隔离回归；群聊创建、导入快照及界面留待后续批次。
