## 2026-11-11

### 修复：由导演结束群聊，资源耗尽保留进度

- 新候选不再按固定发言条数完成，每条保存后继续询问导演；资源预算耗尽标记暂停，支持原候选继续，旧快照语义不变。
- 结束决定先保存检查点，最终提交失败可零模型调用恢复；前端增加暂停提示与直接继续入口，保留失败前缀与版本隔离。

### 修复：群聊复用单聊抽屉与消息组件

- 群聊接入原单聊抽屉、气泡、角色状态与好感度进度条，按成员切换；移除生成中的重复状态文字，保留错误查询入口。
- 复用单聊记忆库搜索与分页，增加成员隔离的只读记忆接口，展示继承与已确认群内记忆及向量索引状态；隔离单聊的写入、朗读和候选操作。

### 清理：移除旧群聊角色生成、格式转换与审查执行

- 删除旧角色 JSON 解析、转换器、格式纠正重试和亲历审查模块；导演仅调度，角色统一复用单聊 XML 与状态解析，调用预算改为 `2K+1`。
- 内部服务同样拒绝恢复旧策略候选，保留旧内容、权限和状态读取；原型工具与回归夹具同步清除旧执行依赖。

### 清理：删除群聊角色 JSON 输出协议残留

- 删除 Prompt 编译器中的旧 v2 JSON 输出契约和覆盖入口，统一复用单聊 XML；旧候选预览也不再要求角色生成 units/status JSON。
- 删除 JSON 风格示例改写和自身 assistant JSON 历史包装，保留旧数据权限过滤；回归核对旧历史读取、单聊示例、PHI 和状态输出。

### 调整：导演明确控制角色回应对象

- 共同群聊复用现有承接引用，让导演同时选择发言成员和回应消息，按本轮完成条数安排多次发言；角色获得明确原文与本人发言序号，继续使用单聊 XML，不增加裁决调用。
- 回应对象随候选冻结并持久保存，续接保留原目标；旧快照不自动升级。回归覆盖 A→B→A、连续发言、回应较早消息和无效目标拒绝，真实测试保留次数合并失败，不以接口成功代替行为通过。

### 调整：先恢复共同群聊基础链路

- 新候选复用单聊 XML、解析与提示词组装，导演仅调度顺序和结束，冻结裁决、格式转换和额外审查；旧候选保留原权限与快照，旧裁决 HTTP 续接明确拒绝并提示重新生成。
- 复用单聊组件提供逐角色提示词预览，模型调用记录分阶段耗时；逐条保存与失败续接由隔离回归核对，真实模型和移动端效果尚未验收。

### 记录：群聊实测失败后的返工要求

- 登记用户要求的协议复用、逐角色展示、等待耗时、发言上限停止行为和移动端界面五项未解决问题，实施入口明确整体未通过验收。
- 本轮仅维护待办与验证边界，不修改代码或部署；后续先用实际角色和失败场景验证，不以自生成简单样本或接口成功代替可用性。

### 调整：放宽群聊自动审查以保持连续对话

- 亲历审查仅对明确的具体往事作硬性判断，模糊判断放行；自然接话、当下感受、玩笑与合理感官细节不逐句追溯出处。
- 发言后判放宽普通互动接触，继续拒绝代写他人台词、决定及关键行动；保留私密心理可见性、来源引用与输出结构校验。

### 修复：群聊首轮回复的格式与思考预算阻塞

- 群聊 v2 不再以单聊 XML 示例作为输出示范；完整旧格式及 JSON 标点错误可在既有重试内独立转换并核对原文、值与状态，修正当下心理和身体反应被当作无依据往事的误判。
- 新 DeepSeek 思考调用预留至少 16K 输出额度，v4 亲历审查单独冻结 low 强度，角色保留用户选择且旧候选不变；界面明确区分截断、格式和审查失败。

### 修复：群聊模型选择与键盘适配

- 输入栏与抽屉接入单聊模型面板，发送及整轮重生成携带点击时冻结的模型、思考开关和强度；配置失败或等待期间离页不提交，续接保留原参数。
- 补上群聊 Android 的 `adjustResize`，修正共享原生键盘高度字段，支持微信及 H5 可见视口占位，并同步焦点滚动与底部留白；真机输入法动画尚待验收。

### 修复：群聊翻页定位与背景跟随边界

- 翻页仅在读取成功且仍处于原页面时恢复位置，离页、切服与切群后的旧请求及延迟滚动回调不再修改当前定位。
- 最新轮次尚无角色发言时保留此前最后发言者的背景；当前明确清空的图像选择不会恢复成历史立绘。

### 修复：群聊抽屉头像打开角色档案

- 抽屉顶部、成员列表和起点资料中的头像可打开对应角色详情，返回保留当前群聊与草稿；跳转期间阻止重复点击，失败可重试。

### 修复：群聊详情复用聊天界面

- 群聊复用单聊顶栏、固定输入栏、气泡、立绘背景与阅读偏好，接入小说排版、字号行距和色调；资料抽屉共用单聊样式，分成员、外观、起点与管理，已有开场不再显示空提示卡。
- 保留独立群聊操作与恢复流程，补充输入保护、采用立绘与预览隔离、图片失败回退的回归，并以虚构数据检查手机尺寸的背景、排版和抽屉。

### 修复：群聊明确口头请求被导演空轮次跳过

- 首条角色发言前，有明确口头回应请求时拒绝导演直接结束，复用有界阶段校正与持久调用预算，耗尽明确失败。
- 保留普通陈述、动作请求、已有回复及旧规划策略的结束规则；暂不调整认知摘要的亲历依据策略。

### 功能：群聊原卡成员的公开开场

- 原卡成员可选择默认或备用开场并编辑、跳过，导入培养人格的成员不插入问候；开场全员可见，创建时冻结，用户发送首条消息才启动生成。
- 新增开场快照迁移，旧群聊不回填；导演、个人上下文和亲历审查读取冻结开场，保留其他成员私有设定隔离，补充混合来源、迟到响应及迁移回归。
