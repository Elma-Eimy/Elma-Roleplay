# 2026-11 更新记录

## 2026-11-05

### 修复：M3-C 失败结果的候选版本

- 整轮服务统一提交失败标记，返回该次真实提交后的 revision；版本竞争或标记失败时保留最后接受的版本，不借用外部写入的新版本。
- 发言提交后收到取消时传回保存版本，再由整轮按该版本清理；补充导演/角色失败、版本竞争及提交后取消回归，单步入口保留独立失败清理。

### 功能：M3-C 可见单元与导演审计

- 内部整轮和隔离 CLI 接入 v2 单元协议，用户原文按码点范围映射，公开台词与私密心理独立知情，状态增量只保存和重放一次；保留显式 v1 兼容。
- 新增候选审计与正常终止原因，调度先提交，正文/单元/权限/状态/后判审计原子保存；迁移保留旧权限并保护有损降级，普通发送继续关闭，真实模型与真机未验收。

### 修复：M3-B 诊断隔离与单次超时

- 个人输入诊断失败改为独立错误码和报告检查，不改变候选业务终态；外部取消继续等待线程清理并传播。
- 模型返回后复核单次绝对期限，拒绝适配器吞掉取消后返回的迟到结果；新增 4 项回归覆盖四个阶段、诊断脱敏与取消边界。

### 工程：群聊 M3-B 整轮执行基础

- 将原型推进收敛到内部整轮服务，加入任务绑定的执行权、统一调用快照、零重试客户端和程序预算；关闭时等待已登记任务、持久化及客户端清理，不开放生成 API。
- 明确用户原文范围与角色多单元的知情设计，状态增量归父发言且只应用一次；细分落库与审计留给 M3-C，新增执行基础与本地 HTTP 专项，真实模型语义未验收。

### 修复：M3-A 预算与收尾取消

- 导演阶段编译将待判正文和阶段字段纳入预算，先省略旧历史，保留本轮前缀；修复旧历史填满快照后短新输入也失败。
- 原型最终终态明确提交成功后返回完成结果，提交失败仍保留取消和失败状态；新增 4 项回归，先复现再修复。

### 工程：群聊 M3-A 导演协议与隔离原型

- 接入严格导演 JSON 协议、有效候选场景快照与临时源码/虚构库原型，离线回放自动选人、知情后判和只读 HTTP；新增 20 项专项，公开生成仍关闭。
- 8 个场景复现调用有界、身份及秘密过滤，也确认混合内容的全文隐藏会丢失公开台词；先修订可见单元设计，真实模型语义与正式编排尚未验收。

### 设计：群聊 M3 导演与有限互动

- 新增 [M3 设计稿](../plans/group-chat/M3_DIRECTOR.md)，定义知情初判、逐步选人、正文后判、整轮执行权、调用预算和候选审计，保留 M2 个人输入隔离。
- 拆分原型、执行基础、审计迁移及联通验收批次；全文粒度、沉默与预算数值待原型验证，尚未实现导演或执行真实模型验收。

### 修复：M2 世界书扫描与失败并发

- 世界书改为扫描个人可见原文，避免 JSON/XML 转义漏触发与包装字段误触发；取消期间数据库失败仍保留取消，失败标记不可写也不覆盖原始错误或暴露正文参数。
- 详情刷新完成后再读取轮次首页，阻止翻页抢占；新增后端 4 项、前端 1 项失败复现回归并修复。

### 功能：群聊 M2-B/C 单步生成与只读发言

- 接入个人可见 Prompt、候选内自身状态重放和内部单步生成，保持世界书及用户原文隔离；正文、知情结果与状态增量原子保存，失败/取消不生成兜底台词，不自动重试。
- 增加只读整轮历史接口和详情展示、Mock 样本读取与请求失效保护；补齐隔离 A → B → A 联通原型，普通发送、导演、候选切换和持续记忆仍属后续模块。

## 2026-11-04

### 修复：M2-A 事务拒绝与关闭运行权

- 群聊内部服务在重置事务前拒绝调用方的待提交修改或活动 SQLite 事务，预读取禁止 autoflush；拒绝时保留调用方修改，避免误回滚。
- 后台 Worker 异常或关闭被重复取消时，等待全部后台任务及聊天流清理后再释放数据库运行权；补充失败复现与取消回归。
