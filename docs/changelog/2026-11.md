## 2026-11-06

- 分开保存用户片段用途、推进请求和感知权限，导演选择可验证的承接依据，提交与角色输入再次校验；复用发言后判检查明确冲突，拒绝不提交，显式续接保留原依据和冻结策略，兼容旧快照及 v1。
- 新增 10 项专项，补可选 JSON 模式与允许请求的世界书扫描；真实 API 174 次、26 轮及程序/审计检查通过，仍保留有限样本和轻微叙事推断边界，详见[群聊 M4 验收](../testing/GROUP_CHAT_M4.md)。

### 修复：群聊个人历史类型与生成身份边界

- v2 个人投影保留获准单元类型，用户原话与其他成员历史资料分开，补充可见顺序及当前身份/既有发言者依据；明确请求与已发生事实、知情与发言需求，保留旧解析和严格权限/输出校验。
- 新增 3 项回归，最终后端全量 720 项通过；真实 API 含中间失败共 460 次，最终实现 189 次仍观察到语义残留与两条冻结验证的无效输出，未宣称完整验收，详见[群聊 M4 交接](../testing/GROUP_CHAT_M4.md)。

### 验收：多人交互边界与叙事请求时序

- 使用真实模型执行 9 个场景、14 轮及 4 轮定向对照，共 117 次请求；核对点名/沉默、角色间借物、双人分工、离场返回、分别私聊和第三人纠正，主批 55 项程序检查与 77 项追加核对通过。
- 正文审阅发现角色提前引用未发生发言，相同简略叙事请求还出现初判全员隐藏、无人回应；明确口头请求的两次对照正常，未修改生产实现，证据与边界见[群聊 M4 交接](../testing/GROUP_CHAT_M4.md)。

### 验收：群聊 M4 真实 API 与角色身份语义

- 使用 `deepseek-v4-flash`、正式后端路由和独立迁移库完成 77 次真实请求，核对候选操作、最终提交故障续接、知情过滤、长原文边界与同名作者；32 项程序检查和 18 项追加核对通过，群聊离线专项 206 项通过。
- 正文审阅与重复调用发现白川误领用户行李、替用户行动，原场景累计 3/3 出现；显式所有权对照单次正常，未修改生产实现。调用统计、证据与未验收范围见[群聊 M4 交接](../testing/GROUP_CHAT_M4.md)。

### 修复：M4-D 迟到恢复与未展示候选确认

- 恢复流程在每次等待读取后重新校验页面，且不抢回用户后来选择的预览；候选或分页查询发现新选择时，必须先刷新主历史才可写入，避免确认尚未展示的候选。
- 删除等待历史和请求记录读取完成；明确拒绝但存储清理失败的请求可保留拒绝标记并重试清理，活动任务可直接查询。新增 8 项回归，前端全量 282 项、专项 61 项、类型和三端构建、文档检查通过，验收边界见[群聊 M4 交接](../testing/GROUP_CHAT_M4.md)。

### 功能：M4-D 群聊整轮交互与请求恢复

- 详情页接入发送、整轮重生成、候选预览/切换、显式续接与撤回；本机预存 UUID，未知提交和离页返回仅通过 GET 恢复，旧响应不能倒退选择，预览不覆盖成员起点。
- 补充可控计时器、存储与延迟响应回归，前端全量 274 项、交互专项 53 项、类型和三端构建、接口文档专项 3 项与文档链接检查通过；真实路由、临时库和模型替身的隔离 H5 操作见[群聊 M4 交接](../testing/GROUP_CHAT_M4.md)，真实模型恢复及 App/微信真机仍待验收。

### 修复：群聊整数参数超出数据库范围

- 为群聊路径 ID、请求中的资源 ID/版本及分页 offset 增加 SQLite 有符号 64 位上限，超范围在资源读取和 SQL 绑定前返回 422，不消费 UUID、触发模型或确认上一轮；合法上限的分页和不存在资源行为保留。
- 新增请求体、路径/分页及成员/来源 ID 的边界回归，核对 stash/pop 后文件恢复完整并清除换行噪音；后端全量 717 项、API 79 项、接口文档专项 3 项、前端 248 项与类型检查通过，文档链接检查无错误。
