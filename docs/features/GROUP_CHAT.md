# 群聊起点与成员管理

[文档导航](../README.md) · [群聊管理 API](../api/GROUP_SESSIONS.md) · [实施进度](../plans/group-chat/README.md)

目前可以创建、查看和删除群聊，为固定成员保存独立的人格起点。群聊发送、角色互动、整轮候选和持续记忆仍未开放，详情页没有发送框。

## 创建和查看

故事首页的“群聊故事”进入独立列表，列表支持刷新和分页，不混入单聊故事。点击“新建”后填写群聊标题、用户昵称与共同设定，选择 2–3 名不同的角色。

每名成员可从原卡开始，或选择该角色的一条单聊作为来源。界面明确提示“导入当前已保存状态与记忆”：导入的是创建时已经落库的状态和有效记忆，不是任意历史时点的还原。具体记忆边界与服务端事务规则见 API 契约。

成员与共同设定创建后固定，当前不提供编辑或逐个增删成员。创建成功进入详情，展示成员、来源模式、导入卡数量、保存时间、好感度、心情、认知与场景。来源单聊之后继续聊天、修改记忆或被删除，不改变已经冻结的群聊起点。

离线 Mock 只支持原卡起步，创建页不提供快照导入选项，并说明尚未支持的能力。

## 提交、失败与删除

创建期间禁用重复提交和成员修改，已发请求使用点击时的参数快照。明确的参数、资源或忙碌错误保留草稿，允许修正后手动提交；超时、断连或提交结果不确定时，页面不提供直接重发，应先返回列表确认是否已经创建。

离页、切换服务器或 A→B→A 切服会使旧请求失效。旧响应不能恢复旧表单、覆盖新列表、清除新请求的忙碌状态或触发跳转。详情页切服后不复用同号故事，要求返回新服务器的群聊列表重新选择。来源选择也按成员和请求版本隔离，移除后重新加入的同名角色不会接收旧来源列表。

同一服务器内返回创建页时，被离页中断的来源读取会重新加载对应页，保留已加载的来源和已选故事。重新确认相同来源模式不会清空选择；切换模式时才重置来源。

删除需要确认整个群聊，界面说明来源单聊和角色卡会保留。确认期间阻止重复操作；离页或切换对象后的过期确认不会发出删除请求。已发送的请求可能在服务端完成，前端失效只阻止迟到回写，不撤销服务端事务。

## 验证范围

流程回归覆盖 H5、App Plus 和微信小程序的提交保护及作用域失效。三端构建分别检查编译兼容，H5 使用隔离临时后端和虚构数据走通首页入口、原卡创建、快照导入、详情、删除和列表刷新，并检查移动端及宽屏布局。

没有操作开发数据库或调用真实模型。App Plus、微信小程序的真机交互，以及后续角色互动质量仍需单独验收；构建成功不代表这些场景已经通过。
