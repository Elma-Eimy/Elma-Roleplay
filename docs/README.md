## 目录约定

- 根目录放项目入口、共享 API 总表和更新日志。
- `docs/api/` 放复杂模块的接口补充规范，使用明确的模块名称，避免 `NEW_`、`FINAL_` 等临时命名。
- `docs/local/` 放个人博客草稿和第三方参考副本，由 Git 忽略，不是运行或构建所需文件。
- `app-backend/` 保留 Python 代码、数据库迁移、测试、依赖清单、后端配置和本地数据。
- `app-frontend/` 保留客户端代码、依赖清单、Vite/TypeScript/uni-app 配置和构建产物。

运行命令分别在 `app-backend/` 和 `app-frontend/` 中执行；提交、分支和推送由根目录的同一个 Git 仓库管理。组件目录不再维护独立的 Git 仓库或重复的 API 总表。

## 维护方式

接口改动时更新根目录的 `API_TABLE.md`；记忆模块涉及筛选、统计或继承规则时，同时更新 `api/MEMORY_API.md`。组件 README 通过相对链接引用共享文档，所有链接都应能在 GitHub 和本地工作区中使用。

新增全栈功能、修复或工程调整时，在 `CHANGELOG.md` 中补充记录。新增文档时同步维护本页的导航。

文档最近一次按代码核对于 2026-10-21。已被实现替代的任务计划和与当前行为矛盾的旧草稿不再保留在工作区；历史变更仍保留在更新日志中。`docs/local/` 中的第三方规范副本用于格式参考，不代表项目完整实现了该规范的所有功能。
