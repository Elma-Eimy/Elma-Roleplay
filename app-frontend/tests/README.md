# 前端回归检查

`charx.test.cjs` 覆盖 H5/微信文件选择与 20 MiB 前置校验、App 明确提示、认证上传、确认重试、新角色与已有角色的头像默认策略、退出/切换目标后的迟到预览清理、服务器切换后的令牌隔离。压缩包验证、临时资源生命周期、确认事务、幂等回执与数据库迁移由后端隔离测试覆盖。

多立绘回归见 `portraits.test.cjs`：接口路径与版本参数、带认证头的跨端上传调用、离线模式明确拒绝，以及故事切换、并发刷新、退出和服务器变更后的迟到响应隔离。图片内容、资源回收与候选/分支恢复由后端隔离回归覆盖；H5 模拟接口交互不替代 App/小程序真机上传验收。

该文件还执行立绘面板的实际 setup 脚本，验证剧情变化替代旧读取、写入期间排队补刷、失败写入后的刷新与错误反馈，以及旧故事写入结束后不能解锁新故事。

在 `app-frontend/` 中执行：

```bash
npm test
npm run type-check
```

测试使用 Node.js 内置测试器和项目已有的 TypeScript 转译器，不新增测试框架依赖，也不会连接真实后端。

- `chat-mutations.test.cjs`：消息编辑、删除、候选切换在换故事、重置和切服后的成功/失败隔离；当前失败不清除其他加载状态；编辑失败保留草稿、重复保存拦截、取消后新编辑的独立状态、旧操作面板与确认回调失效；三端恢复在切服后停止且不重发聊天 POST。
- `connection-lifecycle.test.cjs`：执行实际连接保存逻辑，验证同地址和存储失败不重置，地址变化后同步清空聊天与人物状态；历史、人物详情和角色列表在 A→B→A 后仍拒绝旧结果，作用域销毁释放订阅。构建器环境变量在加载测试模块时替换，不加载真实配置或连接后端。

- `character-card.test.cjs`：导入关闭/换卡后的旧响应隔离、字段替换与空项补充、第三方扩展保留、开场原始索引及三端文件选择。
- `character-translation.test.cjs`：中英文阅读切换、原卡及隐藏 Prompt 隔离、手动翻译、缓存与生成竞态、换卡失效、失败保留译文和在线 API / 离线 Mock 边界。
- `memory-consolidation.test.cjs`：手动预览、逐组选择、应用/撤销刷新、重复点击保护、分批游标、关闭/换故事/换服务器的旧响应隔离，以及整理请求和离线边界。

- `stream.test.cjs`：跨字节 UTF-8、SSE 帧边界、错误与截断响应、H5 取消、小程序分块与整包接收、取消请求及禁止重复 POST。
- `app-stream.test.cjs`：App XHR 分块与收尾、HTTP/协议/网络错误、取消与旧连接回调隔离、桥接实例隔离，以及逻辑层同步失效和终态去重。
- `entry-case.test.cjs`：入口文件与导入的精确大小写。
- `session-lifecycle.test.cjs`：历史请求乱序、分页失效、切换会话后的旧回调，以及人物详情的异步隔离。
- `session-api.test.cjs`：领域拆分后的请求方法、路径、参数与兼容导出；完整会话分页、错误传递，以及离线分支继承、消息候选和记忆筛选/修改。
- `helpers/load-ts.cjs`：内存加载实际 TypeScript 源码，以替身注入网络和平台接口。Store 使用实际 Vue/Pinia；测试加载器只筛选本次涉及的条件编译块。

这些测试不模拟完整的 uni-app 编译器或手机运行环境。修改跨端网络逻辑后，还需要执行：

```bash
npm run build:h5
npx --no-install uni build -p app-plus
npm run build:mp-weixin
```

三个平台共用 `utils/chatStreamProtocol.ts` 解析 SSE 消息和终态。App 的 `ChatStreamBridge.vue` 通过 renderjs/XHR 接收字符文本，由 `ownerInstance.callMethod` 回传逻辑层；字节解码器用于 H5 和 uni 请求任务。真机上的分块回调、页面退出和网络中断仍需按目标平台验收。

CHARX 回归还覆盖：保存响应丢失后的回执恢复、未知结果下冻结原请求、校验失败后解锁修改、过期状态和服务器切换后的旧回调丢弃；素材类型/正文引用/关键词筛选与批量选择、缩略图增量缓存、加载期间改变筛选及初次上传的忙碌状态、设定同步参数和显式关闭世界书同步。App 测试覆盖缺少文件选择器时的提示，不代表已验收真机文件选择。
