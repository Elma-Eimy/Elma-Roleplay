# AI Roleplay Frontend

[项目说明](../README.md) · [共享 API](../API_TABLE.md) · [文档索引](../docs/README.md)

面向手机端的跨平台 AI 角色扮演客户端，基于 Vue 3、uni-app、Vite、Pinia 和 TypeScript 构建，可运行于 Android/iOS App、H5 与微信小程序。

界面采用“清新角色画册 + 柔光叙事聊天”的视觉方向：首页用于继续故事，角色库用于浏览人物，聊天页聚焦长篇阅读，人物详情则以档案、世界、记忆和故事线组织内容。

## 功能概览

- 流式角色对话、Markdown 消息与思考内容展示
- 可按会话选择纯净背景或居中清晰角色背景；半透明消息、顶栏与输入区叠在同一画面，输入期间保留人物
- 情绪、好感度、认知状态与按故事线隔离的长期记忆管理
- 记忆库中的“整理记忆”由用户手动触发，提供“检查新增与变更”和“重新检查全部”，显示当前有效原卡的已检查/待检数量；支持分批预览、逐组编辑保存与忽略恢复、选择应用和撤销，保留模型原稿、原卡与来源并提示逐组冲突。仅处理当前故事的重复内容与同一次事件碎片，不做跨批关联；已检查不代表已应用，详见 [记忆整理契约](../docs/api/MEMORY_API.md#可预览的存量记忆整理)。
- 多候选回复切换、消息重生成和 TTS 语音朗读
- 从历史消息创建故事分支，并通过分支树切换时间线
- 创建、编辑和导入 PNG/JSON 角色卡
- 人物档案、角色专属世界书及公共世界书绑定
- SillyTavern JSON 世界书导入、编辑和词条管理
- Prompt 组装结果预览与模型生成参数配置
- 模型与思考档位直接选择，新故事复制默认配置后独立保存，详见[模型设置](../docs/MODEL_SELECTION.md)。
- 聊天侧栏展示和编辑场景、姿势、衣着与位置，自动沿用未变化状态并保护编辑草稿，详见[角色状态](../docs/ROLE_STATE.md)。
- 运行时服务器地址和 `X-API-Key` 配置
- App、H5、微信小程序三端构建

## 界面结构

| 区域 | 用途 |
| --- | --- |
| 故事首页 | 最近故事、角色横廊、快捷创建与导入 |
| 角色画册 | 浏览角色卡、进入人物档案、创建新角色 |
| 人物档案 | 查看档案、世界设定、故事记忆导航与故事线 |
| 叙事聊天 | 阅读和发送消息、切换候选、选择会话背景、管理分支、状态与当前故事记忆 |
| 设置 | 外观、模型、记忆与世界、连接安全、数据管理 |

应用使用统一的语义颜色、圆角、间距、按钮和状态组件，并支持系统“减少动态效果”偏好。加载、空数据、错误与离线状态采用一致的视觉反馈。

## 角色卡导入与展示

首页和画册的导入入口会打开角色卡预览。先选择文件，再检查人物设定、全部开场、作者说明与内嵌世界；确认前保留当前编辑内容。导入到已有角色时可以替换设定，或只补充空项。创建和编辑先进入草稿，人物档案中的更新在确认后保存。

角色可单独存入画册，也可选择开场后开启故事。档案与故事创建共用支持搜索、分页和全文预览的开场浏览器，编辑页可以维护备用开场。作者说明采用分页阅读，角色标签默认折叠，作者和角色版本随导入保存。完整行为与格式边界见 [角色卡说明](../docs/CHARACTER_CARDS.md)。

## 故事记忆

长期记忆按会话故事线隔离保存，并支持从上游故事继承，避免不同平行分支的经历和关系互相混淆。

- 在聊天页中，记忆库用于管理当前故事的记忆，可搜索、筛选、新增、编辑和删除本故事记忆。
- 记忆卡片展示中文类型、来源、继承状态、替代状态和原始权重；筛选范围包括全部、当前故事、继承和已替代。
- 在人物档案中，记忆区域是故事线导航，而不是角色全部记忆的扁平列表。
- 人物档案会突出最近活跃故事，并列出其他故事、继承来源及有效/继承记忆统计；选择具体故事后才会打开对应的记忆库。
- 从人物档案进入记忆库时，标题会明确显示正在查看的故事名称，筛选中的本地记忆标记为“此故事”。
- 记忆分类、搜索和分页由服务端完成，分类数量来自后端 `facets`，避免只筛选当前 20 条而产生假空状态。

## 聊天背景

聊天页将现有角色图片居中铺在消息背后。可以在右侧抽屉的“对话设置 → 聊天背景”中选择角色立绘或纯净背景。

- 角色背景保留清晰度和原色，仅在顶底加局部渐变；深色半透明消息气泡、顶栏和紧凑输入区共同叠在画面上，输入时不隐藏人物。宽屏只限制消息阅读宽度，人物仍居中。
- 未选择额外立绘时复用角色头像图片，手机以 `aspectFill` 居中填满；900px 及以上宽屏使用 `aspectFit` 保留完整人物，以柔化的同图补满周围。手机上的不同图片可能发生裁切，尚未提供构图位置或缩放设置。
- 人物档案的“档案”页签与聊天侧栏均可添加、预览、改名、删除额外立绘。支持 PNG/JPEG/WebP，不要求情绪标签或套图；聊天侧栏可手动选图或恢复沿用头像，纯净背景模式下选图不自动开启背景。
- 手动立绘选择保存在后端当前剧情节点；刷新、切候选、重新生成、删除消息及分支均按有效消息恢复，分支不读取父线未来或之后的手动选择。素材属于角色、由所有故事共用；删除后相关故事回退头像。普通卡无需新增配置。
- 角色卡导入面板新增保守的 CHARX/ZIP 入口（默认 20 MiB），先预览设定、开场和图片再确认；新角色直接创建，已有角色仅补图并保留设定和头像，主动选图才换头像。图片预览每页 12 张，立绘库每次加载 24 张。详见[角色卡说明](../docs/CHARACTER_CARDS.md#charx-首版)。
- H5 可选择本地包，微信小程序从聊天文件选择；App 首版提示改用 H5 导入后在 App 使用。不支持模块脚本、套图、开场自动关联或情绪自动切换；离线 Mock 明确提示暂不支持多立绘和 CHARX。
- 没有图片或加载失败时回退为浅色聊天；沉浸模式的文字语义只作用于消息、顶栏与输入区，不改变抽屉和编辑弹窗。
- 纯净/角色背景模式按 `sessionId` 保存在当前设备；具体立绘选择保存于后端 SQLite，需要正常执行新增迁移。
- 不同故事可以使用不同背景；新建分支会继承父会话设置，删除会话时会同步清理本地偏好。
- 未保存偏好或清除应用数据后默认尝试角色背景；明确保存过的纯净模式保持不变。本地偏好不会跨浏览器或设备同步。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| Vue 3 + Composition API | 页面与组件开发 |
| uni-app | App、H5、小程序跨端运行 |
| Vite 5 | 开发服务器与构建 |
| Pinia | 会话、角色和聊天设置状态管理 |
| TypeScript | 类型约束与接口定义 |
| markdown-it | 安全 Markdown 渲染 |
| vue-tsc | Vue 单文件组件类型检查 |

项目当前使用组件内 CSS 与 `src/App.vue`、`src/uni.scss` 中的语义设计变量，没有启用 UnoCSS。

## 快速开始

### 环境要求

- Node.js 当前 LTS 版本
- npm
- 可访问的配套后端 API；也可以在源码中启用本地 Mock 模式
- App 调试与发行需要 HBuilderX
- 微信小程序预览需要微信开发者工具

### 安装依赖

以下命令均在仓库的 `app-frontend/` 目录中执行。从仓库根目录进入：

```bash
cd app-frontend
```

```bash
npm install
```

### 启动开发环境

```bash
# H5
npm run dev:h5

# 微信小程序
npm run dev:mp-weixin

# App Plus CLI 编译
npx uni -p app-plus
```

微信小程序开发产物位于 `dist/dev/mp-weixin`。App 端也可以直接通过 HBuilderX 导入项目后运行。

## 后端连接

默认 API 地址为：

```text
http://127.0.0.1:8000
```

可以通过环境变量设置初始地址：

```dotenv
VITE_API_BASE_URL=http://192.168.1.100:8000
```

也可以在应用内进入：

```text
设置 → 连接与安全 → 服务器连接地址
```

应用内保存的地址优先于环境变量。如果后端配置了访问控制，请在同一区域填写对应的 `X-API-Key`；地址和密钥保存在当前设备的 uni-app 本地存储中。

完整接口约定见根目录的 [API 总表](../API_TABLE.md)，记忆筛选与故事导航的详细语义见 [记忆模块 API](../docs/api/MEMORY_API.md)。

### Mock 模式

本地 Mock 数据开关位于 `src/api/config.ts`：

```ts
export const USE_MOCK = false;
```

将其改为 `true` 后，角色、会话、消息和世界书会使用本地存储中的示例数据。设置页的“数据管理”可以重置这些 Mock 数据。

## 跨端注意事项

API 的模块边界与兼容入口见 [API 模块约定](src/api/README.md)。

- App 端选择角色卡时使用相册中的原始 PNG，以免系统压缩破坏卡片元数据；H5 等平台可选择 PNG 或 JSON。
- 三端流式协议由 `utils/chatStreamProtocol.ts` 统一解析。App 使用独立的 `ChatStreamBridge.vue` 和 `api/transports/appStream.ts` 进行 renderjs/XHR 桥接，通过实例方法回传事件，请求头传递 `X-API-Key`；页面不再直接解析流式响应。
- Android 聊天页使用 `adjustResize` 适配软键盘；iOS 通过键盘高度监听补偿输入区。
- 音频资源属于受保护接口时，同样通过请求头携带 `X-API-Key`。
- 自定义 TabBar 会隐藏 uni-app 原生 TabBar，页面底部布局需要保留安全区和导航高度。

## 发布

H5 和微信小程序使用上面的生产构建命令。App 发行建议在 HBuilderX 中打开项目，选择“发行 → 原生 App 云打包”，生成 Android 或 iOS 安装包。

CHARX 预览显示保留、跳过及兼容性待确认清单，确认前汇总新建/追加操作及头像变更。默认按内容跳过已有立绘；保存响应丢失时查询后端回执，未确定结果前锁定选择并允许重试原确认。
